# Movie Recommender System

An educational MovieLens project exploring rating patterns, genre similarity, item-based collaborative filtering, and dimensionality reduction. The accuracy workflow compares a user-mean baseline with a tuned KNN predictor using RMSE and MAE.

By [Arian Shamsabadi](https://github.com/TheRealShamsaba).

## Repository-recorded results

These values come from the checked-in [`benchmark_summary.csv`](benchmark_summary.csv), rounded to four decimal places. They were not independently reproduced during the documentation cleanup and are not a production-quality or external benchmark claim. Lower RMSE and MAE indicate smaller rating-prediction errors.

| Model | RMSE | MAE |
| --- | ---: | ---: |
| User-mean baseline | 1.0417 | 0.8346 |
| Tuned KNN (`k=100`, cosine) | 0.9735 | 0.7632 |

The current analysis code uses an 80/20 random ratings split with `random_state=42`, then five-fold cross-validation on the training split over six `k` values and three distance metrics. The stored summary does not include a dependency-version manifest or the full per-fold results. [`accuracy_diagnostics.png`](accuracy_diagnostics.png) is the repository-recorded diagnostic plot; `knn_cv_results.csv` is generated by the pipeline and is not tracked.

## Set up locally

Use Python 3.11 or 3.12 and run commands from the repository root so relative data paths resolve correctly.

```bash
git clone https://github.com/TheRealShamsaba/Movie-Recommender-system.git
cd Movie-Recommender-system
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy pandas matplotlib seaborn scipy scikit-learn fuzzywuzzy python-Levenshtein
```

On Windows, activate with `.venv\Scripts\activate` instead. Dependencies are not pinned in this repository, so this dependency list does not reconstruct the recorded benchmark environment exactly. A fresh dependency installation and the full analysis have not been validated in this documentation pass.

## Safe inspection and syntax checks

The stored CSV and plot can be inspected without running the analysis. This syntax check also avoids executing either script and requires only Python:

```bash
python -m py_compile recommend.py app.py
```

There is no automated test suite in this repository. Syntax checks do not verify the numerical results or Flask behavior.

## Run the full analysis deliberately

```bash
python recommend.py
```

This runs exploratory plots, similarity calculations, SVD, and the full KNN accuracy pipeline. The grid evaluates 18 configurations across five folds and can take substantial time. Plot windows may pause execution until closed. A completed run writes `knn_cv_results.csv` and overwrites `benchmark_summary.csv` and `accuracy_diagnostics.png` in the working directory.

**Importing `recommend.py` also starts the full workflow.** It has no `if __name__ == "__main__"` guard, and `run_accuracy_pipeline()` depends on module-level data and fitted objects. It is not currently a side-effect-free library entry point.

The full analysis was not rerun for this documentation change. The recorded metrics above remain the original repository artifacts.

## Optional Flask demo

The Flask app is independent of `recommend.py`: it fetches tutorial `ratings.csv` and `movies.csv` files from public S3 URLs at startup and builds its own matrices. It does not load the local MovieLens analysis or its tuned model, and running `recommend.py` first is not required.

After installing the analysis dependencies, add Flask and start the local development app:

```bash
python -m pip install Flask
python app.py
```

Open `http://127.0.0.1:5000`. Startup needs network access and computes a dense movie-similarity matrix. The form supports fuzzy title matching and item-neighbor recommendations. This is a development demo with debug mode enabled, not a deployed service.

Known limitations include limited form validation and a neighbor-selection loop that currently returns one fewer result than the requested `k`. A bounded offline smoke check exercised the home and recommendation routes with synthetic data and confirmed these limitations. The remote-data startup was not run during this documentation pass; the stored benchmark does not evaluate this app.

## Interpretation and next steps

- The evaluation measures rating prediction on one dataset and random split; it does not measure recommendation relevance for new users, ranking quality, or live user outcomes.
- Sparse ratings and unseen users or movies limit recommendations. The accuracy predictor falls back to a user's training mean or the global mean when needed.
- Separating reusable functions from execution, pinning dependencies, and adding small regression tests would make future benchmark reproduction easier.
